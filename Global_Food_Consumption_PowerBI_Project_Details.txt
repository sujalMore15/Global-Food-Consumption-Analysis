# 🌍 Global Food Consumption Intelligence Dashboard | Power BI

## 📌 Project Overview

**Global Food Consumption Intelligence Dashboard** is an interactive Business Intelligence and Data Analytics project developed using **Microsoft Power BI**.

The project analyzes global food consumption across **countries, areas, regions, income groups, food categories, and years**. The objective is to transform raw food-consumption data into an interactive dashboard that helps users identify consumption patterns, compare geographical and income-based differences, analyze yearly trends, and quickly identify important KPIs.

The project demonstrates an end-to-end Power BI workflow:

```text
Raw Dataset
    ↓
Data Import
    ↓
Data Cleaning & Transformation
    ↓
Data Modeling
    ↓
DAX Measures
    ↓
Interactive Visualizations
    ↓
Dashboard
    ↓
Business Insights
```

---

# 🎯 Project Objectives

The main objectives of this project were:

- Analyze total global food consumption.
- Compare food consumption across countries and areas.
- Analyze consumption across geographical regions.
- Compare consumption between different income groups.
- Analyze consumption by food category.
- Identify high-consumption countries/areas.
- Analyze total consumption over time.
- Understand yearly consumption trends.
- Create interactive filters using Power BI slicers.
- Build KPI cards for quick decision-making.
- Convert raw data into meaningful business intelligence insights.
- Present the analysis through an interactive and visually engaging dashboard.

---

# 🧩 Business Problem

Raw food-consumption datasets can contain a large number of countries, categories, years, regions, and income classifications. Looking at the raw table alone makes it difficult to identify patterns.

This project solves that problem by providing an interactive dashboard where users can answer questions such as:

- Which country has the highest consumption?
- What is the total food consumption?
- How does consumption vary by region?
- How does consumption vary by income group?
- Which areas contribute the most to total consumption?
- Which food categories have the highest consumption?
- How does consumption change from year to year?
- How many countries are represented?
- How many food categories are available?
- What is the average food consumption?
- What happens to the analysis when a specific year, area, or income group is selected?

# 🧹 2. Data Cleaning & Transformation

Data preparation was performed using **Power Query**.

The transformation stage focused on preparing the raw data for reliable analysis.

Typical preparation steps included:

```text
1. Open Power Query
2. Review column names
3. Check data types
4. Identify numerical fields
5. Identify categorical fields
6. Prepare Year as a time field
7. Prepare Area/Country fields
8. Prepare Region fields
9. Prepare Income Group fields
10. Prepare Food Category fields
11. Check missing/inconsistent values
12. Validate the consumption field
13. Apply transformations
14. Close & Apply
```

The purpose of this stage was to ensure that the dataset could be correctly aggregated and filtered inside Power BI.

# 📐 4. DAX Measures

DAX was used to create calculated measures for the dashboard.

## Total Food Consumption

```DAX
Total Food Consumption =
SUM('Food Consumption'[Consumption])
```

This measure calculates the total consumption represented in the current filter context.

---

## Average Food Consumption

```DAX
Average Food Consumption =
AVERAGE('Food Consumption'[Consumption])
```

This measure calculates the average consumption value.

The dashboard displays an average value of approximately:

```text
377.26K
```

depending on the selected filter context.

---

## Count of Food Categories

```DAX
Count of Food Categories =
DISTINCTCOUNT('Food Consumption'[Food Category])
```

The dashboard shows:

```text
107
```

food categories in the relevant dataset/filter context.

---

## Count of Countries

```DAX
Count of Countries =
DISTINCTCOUNT('Food Consumption'[Country])
```

This measure counts unique countries.

---

## Maximum Consumption

```DAX
Maximum Consumption =
MAX('Food Consumption'[Consumption])
```

This identifies the maximum individual consumption value in the current filter context.

A dashboard KPI from the project shows a maximum value of approximately:

```text
92.03M
```

---

## Minimum Consumption

```DAX
Minimum Consumption =
MIN('Food Consumption'[Consumption])
```

This identifies the minimum consumption value in the current filter context.

---

## Consumption by Year

Total Consumption by Year =
